## Create and destroy

```ts
import { createChart } from "@wicklib/core";

const chart = createChart(container, {
  autoSize: true,
  locale: "en-US",
  timezone: "UTC",
  layout: { background: "#0b0e14", textColor: "#d1d4dc" },
  grid: {
    vertLines: { color: "#161b24" },
    horzLines: { color: "#161b24" },
  },
});

chart.destroy();
```

The chart tracks size with `ResizeObserver` when `autoSize` is enabled. Call `resize()` when
using a fixed-size container that changes outside CSS.

## Renderers

Canvas2D is the default. The experimental hybrid WebGL2 backend is available at creation:

```ts
const chart = createChart(container, { renderer: "webgl2" });
```

WebGL2 renders series and indicator geometry; text, axes, annotations, drawings, overlays,
and crosshair remain on Canvas2D. Canvas2D is used automatically if WebGL2 is unavailable.
See [Renderers](/docs/renderers) for the target workload and tradeoffs.

## Options

Chart options cover:

- Layout: background, base text color/font, and shared axis line/text/font styling.
- Grid: vertical and horizontal line colors and visibility.
- Crosshair: mode, colors, labels, and line styles.
- Interaction: wheel, drag, pinch, axis drag, and double-click reset.
- Time scale: spacing, margins, visible bar limits, labels, and sessions.
- Price scale: auto-scale, inversion, margins, border, and mode.
- Extensions: snapshotted at chart creation.

Runtime option patches use `chart.setOptions()`. Changes are merged with current values.

## Axis styling

Axis labels and borders can be styled independently from the rest of the chart:

```ts
const chart = createChart(container, {
  layout: {
    textColor: "#d1d4dc",
    axisLineColor: "#2a2e39",
    axisTextColor: "#9ca3af",
    axisFontSize: 11,
  },
});

chart.setOptions({
  layout: { axisTextColor: "#f3f4f6", axisFontSize: 12 },
});
```

`axisTextColor` falls back to `layout.textColor`, and `axisFontSize` falls back to
`layout.fontSize`. `axisLineColor` falls back to the price and time grid line colours
respectively. Axis text styling covers axis ticks, last-value labels, and price-line axis labels;
it does not affect the legend, drawings, or plot text. Crosshair price/time boxes use the same
chart-aware contrast surface as stats boxes, with automatic text contrast. Axis borders only use
`axisLineColor` while their `borderVisible` option is enabled.

## Price scales

Price scales are linear by default. Switch every pane to logarithmic mode at runtime, or update
a single pane through its series:

```ts
chart.setOptions({ priceScale: { mode: "logarithmic" } });
series.priceScale().setOptions({ mode: "logarithmic" });
```

Logarithmic mode requires positive prices. Explicit non-positive ranges throw
`INVALID_ARGUMENT`; auto-ranges containing non-positive values are ignored so the last valid
range remains. Margins are applied in log space.

## Panes

```ts
const pane = chart.addPane({ height: 160 });
const series = chart.addSeries(SomeSeries, { paneId: pane.id });
```

Panes share the time axis and own independent price scales. Removing a pane removes its series,
indicators, drawings, and overlays.

## Interactions

- Drag to pan.
- Wheel to zoom; horizontal trackpad movement pans time.
- Drag the time axis horizontally to zoom time.
- Drag the price axis vertically to scale price.
- Double-click the price axis to restore auto-scale.
- Pinch to zoom on touch.
- Arrow keys pan; `+` and `-` zoom; `Home` fits.

Disable individual interactions with `interaction.wheel`, `interaction.drag`,
`interaction.pinch`, `interaction.axisDrag`, and `interaction.axisDoubleClickReset`.

## Reset

`chart.resetView()` fits the time scale and restores auto-scale on every pane.

## Events

The chart emits:

- `ready`
- `crosshair`
- `visible-range`
- `click`
- `data-loading`
- `error`
- drawing lifecycle events
- `drawing-selection`
- `drawing-double-click`

All subscriptions return an unsubscribe function and are safe after destruction.

## Accessibility

The chart root is focusable and announces drawing selection through a polite live region.
Delete/Backspace removes selected drawings, `[` and `]` navigate between drawings, and
Cmd/Ctrl+A selects all drawings.
