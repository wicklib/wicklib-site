Drawings are chart annotations anchored in time and price. They survive pan, zoom, and resize.

## Tools

The built-in catalog includes:

- Lines: trend line, ray, extended line, trend angle, arrow, horizontal line, horizontal ray,
  vertical line, cross line.
- Channels: parallel channel, regression trend, flat top/bottom, disjoint channel, Fib channel,
  pitchfork, Schiff pitchfork, and modified Schiff pitchfork.
- Fibonacci: retracement, extension, and Fib time zone.
- Gann: Gann fan.
- Speed: speed lines.
- Shapes: rectangle and circle.
- Positions: long position, short position, and legacy long/short position.
- Ranges: price range, time range, and date/price range.
- Patterns: Elliott impulse, correction, triangle, double combo, and triple combo.
- Freehand: brush, highlighter, and path.
- Text.
- Measurement: measure and stats line.

Use `DRAWING_TOOL_CATALOG` to build host menus. It provides tool definitions, categories, and
the applicable settings for each tool.

## Drawing presentation

Theme-aware colors and drawing presentation are configured per drawing:

```ts
drawing.setOptions({
  color: "theme",
  fillColor: null,
  showLine: true,
  extendLeft: true,
  extendRight: true,
  showMidpoint: true,
  priceLabels: "selected",
  timeLabels: "selected",
  stats: "selected",
  statsFields: ["range", "change"],
  statsPosition: "auto",
});
```

- `"theme"` resolves to the chart layout text color. `""` and `null` clear color overrides.
- `showLine: false` hides line geometry while keeping labels, text, and stats.
- Trend lines support left/right extension, midpoint dots, endpoint price/time axis labels, and
  styled text.
- `priceLabels` and `timeLabels` are `never`, `selected`, or `always`.
- Price labels render endpoint prices on the price axis. Time labels render endpoint times on the
  time axis and skip anchors outside the visible plot.
- `stats` is `off`, `selected`, or `always`.
- `statsFields` orders the visible stats. Fields are `range`, `change`, `bars`, `date`,
  `timeRange`, `duration`, and `angle`. Omit it to keep the built-in set. `date` is date-only;
  `timeRange` includes hours/minutes and seconds when the time scale shows seconds. `duration`
  shows the elapsed first-to-last anchor span in compact units, such as `2h 15m` or `3d 4h`.
- `statsPosition` is `auto`, `left`, `center`, or `right`. Left follows the start anchor, center
  follows the midpoint, and right follows the end anchor. Use start/end only for non-straight
  tools such as Elliott waves.
- Stats include price range, percentage change, bars, date range, and angle where applicable.
  The box has no border and selects a light or dark surface automatically for chart contrast.
- Text supports normal/bold/italic styles and top/middle/bottom vertical alignment. Horizontal
  left/right places text outside the start/end anchor; center places it at the midpoint.

## Modern drawing styles

### Consistency pass

- All drawing tools use the shared `#787b86` default line colour.
- Horizontal/vertical text supports independent left/center/right and top/middle/bottom placement.
- Parallel Channel has six fixed handles: three along each channel line.
- Parallel Channel middle line is dashed by default.
- Stats boxes no longer clamp to the left edge.
- Elliott stats boxes use the normal chart stats font size.
- Arrow exposes the same presentation settings as Trend Line.
- Rectangle middle line defaults off.
- Flat Top/Bottom, Disjoint Channel, and Fib Channel use channel/Fibonacci style settings.
- Circle supports fill/line visibility and text.
- Path supports line style.
- Text borders honour border radius.
- Legacy Long/Short Position is hidden from the new-tool catalog but remains loadable.

### Interaction polish

- Channel interiors are click-through; only channel lines and handles are interactive.
- Arrow now uses trend-line presentation: extensions, styled text, and optional price/time labels.
- Horizontal and vertical lines drag only on their perpendicular axis, share the same default
  colour, support styled text, and expose axis labels (selected by default). Cross Line exposes
  both price and time axis labels.
- Rectangle uses eight handles: four corners and four edge midpoints. It supports text, extend
  left/right, fill visibility, and a styled middle line.
- Position stats now include `lossPercent`, shown by default.
- Measure is transient, removed after use or when another tool starts, and has no settings.
- Path drawings show handles for every authored vertex.
- All selection knobs use 4px rounded corners.

### Shift angle snapping

Hold Shift while drawing or dragging line-based drawings to snap the active segment to the
nearest 45-degree screen angle. This applies to trend lines, rays, extended lines, arrows, trend
angles, measure/stats lines, Gann fans, parallel/Fib channels, flat channels, speed lines,
pitchforks, and disjoint channels. Releasing Shift restores free-angle drawing. Shift takes
priority over magnet direction while preserving the magnet-snapped length.

- Brush, highlighter, and path now support `lineOpacity` and only show selection handles at their
  endpoints.
- Parallel Channel removes its left/right borders and supports independent top/middle/bottom
  line colors, widths, and styles. The middle line is enabled by default; background fill is off
  by default. Extend left/right and background opacity are configurable.
- Regression Trend uses the same top/middle/bottom line settings, channel background, and a
  full-range selection hit area.
- Fib Retracement and Fib Extension accept per-level `fibLevels` settings: ratio, visibility,
  color, width, style, label visibility, and label color. Fibonacci background fill, extend
  left/right, and shared label styling are configurable.
- Price Range now draws only top/bottom lines. Time Range draws only left/right lines. Both keep
  fill backgrounds and extension settings.
- Text drawings support font family, size, bold/italic, alignment, background color/opacity,
  border color/width/radius, and padding.

Automatic linear price precision now keeps at least two decimal places, so prices such as BTC
around 67,000 display cents. Explicit `priceFormat.precision` or `priceFormat.minMove` still
override the automatic value.

## Position drawings

`LongPosition` and `ShortPosition` place with one click. The initial setup uses recent volatility
(ATR) for the stop and a 1:2 target ratio:

```ts
const position = chart.addDrawing(LongPosition, {
  anchors: [{ time, price: entryPrice }],
  options: {
    stopColor: "#ef5350",
    targetColor: "#26a69a",
    labelTextColor: "#ffffff",
    accountSize: 10000,
    riskPercent: 1,
    leverage: 1,
    contractSize: 1,
    positionStatsFields: ["loss", "riskAmount", "entry", "profit", "riskReward"],
  },
});
```

The generated drawing has four draggable anchors: entry, stop, target, and right edge. Entry
moves freely; stop/target move vertically; the right edge moves horizontally. Stop and target
zones are filled without borders, and only the entry line remains.

Stop, entry, and profit each get a zone-coloured, rounded stats box instead of a simple label.
Stats-box text uses `labelTextColor` without automatic contrast and `labelFontSize` for size.
`statsPosition` aligns the boxes left, center, right, or auto; they are not clamped to the chart's
left edge. `priceLabels` controls both axis labels and stats boxes: `never` hides both, while
`selected` shows both only for the selected drawing.

Position sizing options include `accountSize`, `riskPercent`, `leverage`, and `contractSize`.
Risk mode derives risk amount, lot size, profit, loss, margin, and R/R. Available position stats
fields are `accountSize`, `lotSize`, `riskPercent`, `riskAmount`, `riskReward`, `entry`, `profit`,
`loss`, `leverage`, and `margin`. Axis price labels use `priceLabels: "always"` by default.

## Range drawings

`PriceRangeDrawing`, `TimeRangeDrawing`, and `PriceDateRange` use two draggable anchors and a
shared settings model:

```ts
chart.addDrawing(TimeRangeDrawing, {
  anchors: [
    { time: startTime, price: lowPrice },
    { time: endTime, price: highPrice },
  ],
  options: {
    color: "#787b86",
    fillColor: "#787b86",
    fillOpacity: 0.1,
    extendTop: true,
    extendBottom: true,
    statsFields: ["bars", "timeRange", "volume"],
  },
});
```

Range settings include line colour/style, fill colour/opacity, `extend` plus individual
`extendTop`, `extendBottom`, `extendLeft`, and `extendRight`, and `labelTextColor` /
`labelFontSize`. Price Range extends left/right by default; Time Range extends top/bottom by
default; Date and Price Range is bounded by default.

Range info boxes show bars, date/time range, price range where relevant, and OHLC volume when
available. Volume is summed from the first visible OHLC series with volume and formatted
compactly.

## Label styling

Labels use the chart layout font size and a filled background by default. Override them per
drawing:

```ts
drawing.setOptions({
  labelPlacement: "auto",
  labelFontSize: 24,
  labelBackgroundVisible: false,
});
```

`labelPlacement` defaults to `auto`. Elliott labels center on their anchor, above local highs and
below local lows. Use `"above"` or `"below"` to force a side. Labels flip inside the pane when
needed.

With `labelBackgroundVisible: false`, the box is skipped and the text uses the drawing-specific
label color. This applies to Elliott, Fibonacci, range, position, Gann, angle, channel, measure,
and stats labels. Text drawings continue to use `fontSize` for their own text.

## Elliott labels

Elliott tools use their built-in label sequence by default. Hosts can override the labels for a
specific degree or convention:

```ts
const wave = chart.addDrawing(ElliottImpulse, {
  anchors,
  options: {
    labels: ["0", "i", "ii", "iii", "iv", "v"],
  },
});

wave.setOptions({
  labels: ["0", "(i)", "(ii)", "(iii)", "(iv)", "(v)"],
});
```

Label overrides are copied, validated, returned by `getOptions()`, and persisted with the
drawing. Degree names, degree catalogs, defaults, and menus remain host-owned.

## Create programmatically

```ts
import { HorizontalLine, TrendLine } from "@wicklib/core";

const level = chart.addDrawing(HorizontalLine, {
  anchors: [{ time: time, price: 105 }],
});

chart.addDrawing(TrendLine, {
  anchors: [
    { time: startTime, price: 95 },
    { time: endTime, price: 108 },
  ],
  options: { color: "#f0b90b", lineWidth: 2 },
});
```

Interactive tools start with `chart.startDrawing(tool)`. The host decides how the tool is
chosen and styled.

## Selection

```ts
chart.selectDrawing(id);
chart.selectDrawing(id, { mode: "add" });
chart.selectDrawing(id, { mode: "toggle" });
chart.selectDrawing(null);

chart.selectedDrawings();
chart.selectAllDrawings();
```

- Cmd/Ctrl-click toggles a drawing in the selection.
- Cmd/Ctrl-drag on empty chart space creates an additive marquee selection.
- Dragging a selected drawing moves the complete selection.
- Delete/Backspace removes all selected unlocked drawings.
- `[` and `]` cycle through drawings.
- Cmd/Ctrl+A selects all drawings.

## Settings

Each drawing exposes its resolved options and partial updates:

```ts
drawing.getOptions();
drawing.setOptions({ color: "#ffffff", lineWidth: 2 });
chart.updateSelectedDrawings({ visible: false });
```

Per-chart defaults apply to new drawings:

```ts
chart.setDrawingDefaults("trend-line", { lineWidth: 2 });
chart.drawingDefaults("trend-line");
```

Use `drawingToolSettings(toolId)` to show only relevant controls. For example, Elliott waves
support labels but not text, while the text tool supports text and font size but not line width
or fill. Filled shapes expose fill color and opacity. Stats Line uses the configured drawing
color; Measure uses directional green/red coloring and remains transient.

Settings precedence:

1. Core defaults
2. Tool defaults
3. Chart-level defaults
4. Explicit creation options

Styles can be changed on locked drawings; locking only prevents geometry changes, movement,
and deletion.

## Editing and events

`drawing-double-click` lets the host open a tool-specific editor, such as a text prompt. Other
events cover creation, selection, updates, removal, and cancellation.

## Persistence

Wicklib serializes drawings but never persists them. The host owns storage, undo/redo, and
sharing.

```ts
const document = chart.serializeDrawings();
chart.loadDrawings(document);
```

Documents are versioned and use stable tool ids.
