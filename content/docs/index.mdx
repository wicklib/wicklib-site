Wicklib is a Canvas-first charting engine for web applications. It is framework-agnostic,
typed end to end, and splits the free Apache-2.0 engine from optional commercial analytics at
the package boundary.

## Packages

| Package                  | Description                                                     |
| ------------------------ | --------------------------------------------------------------- |
| `@wicklib/core`          | Chart, series, panes, indicators, drawings, annotations, export |
| `@wicklib/indicators`    | Built-in indicator definitions                                  |
| `@wicklib/react`         | React mount wrapper and `useChart`                              |
| `@wicklib/script`        | WickScript compiler, QuickJS runtime, and free `ta.*` functions |
| `@wicklib/script-editor` | Monaco editor with generated WickScript declarations            |
| `wicklib`                | Umbrella package for core and indicators                        |

The commercial add-on lives in `@wicklib/pro` and consumes the published core entrypoint only.

## Design rules

1. `@wicklib/core` has zero runtime dependencies.
2. Every plugin declares `@wicklib/core` as a peer dependency.
3. Rendering is Canvas2D behind a layered renderer.
4. Public API changes are gated by API Extractor.
5. Hosts own persistence, accounts, data transport, and product UI.
