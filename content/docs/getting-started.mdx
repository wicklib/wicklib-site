## Install

```sh
pnpm add @wicklib/core
```

Add the indicator catalog if you need built-in indicators:

```sh
pnpm add @wicklib/indicators
```

WickScript and its editor are separate opt-in packages.

## Render a chart

```ts
import { CandlestickSeries, createChart } from "@wicklib/core";

const chart = createChart(document.getElementById("chart")!, {
  autoSize: true,
  timeScale: { maxVisibleBars: 720 },
});

const series = chart.addSeries(CandlestickSeries, {
  title: "BTC/USD",
  upColor: "#26a69a",
  downColor: "#ef5350",
});

series.setData([
  { time: Date.UTC(2024, 0, 1), open: 100, high: 105, low: 95, close: 102 },
  { time: Date.UTC(2024, 0, 2), open: 102, high: 108, low: 100, close: 106 },
]);

chart.timeScale().fitContent();
```

The container needs a measurable width and height. With `autoSize` enabled, Wicklib tracks it
with a `ResizeObserver`.

## Important: time is milliseconds

All public time values are non-negative integer **milliseconds** since the Unix epoch. Convert
exchange data that uses seconds before calling `setData`, `update`, or `setMarkers`.
