## Status

Wicklib is in Phase 1. The public API exists as typed stubs and every function throws
`WICKLIB_NOT_IMPLEMENTED`. Do not use it in production yet.

## Packages

| Package                  | Status  | Tier             |
| ------------------------ | ------- | ---------------- |
| `@wicklib/core`          | stubbed | free, Apache-2.0 |
| `@wicklib/indicators`    | planned | free             |
| `@wicklib/react`         | stubbed | free             |
| `@wicklib/script`        | planned | free runtime     |
| `@wicklib/script-editor` | planned | free             |
| `@wicklib/pro`           | stubbed | commercial       |

## Roadmap

1. Foundation: toolchain, CI, API seams. Current.
2. Core rendering: scales, series, interactions, datafeed.
3. Indicators and drawings.
4. WickScript runtime and editor.
5. Commercial analytics in `@wicklib/pro`.

## Installing

Packages are not published yet. The first prerelease will be available under the `next`
dist-tag.
